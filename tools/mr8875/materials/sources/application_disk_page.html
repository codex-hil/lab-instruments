Specifications

1.The file below contains the following for resources for HIOKI’s MEMORY HiCORDERs and MEMORY HiLOGGERs.
(1) Description of transfer commands used with the GP-IB, RS-232C and LAN interfaces
(Compatible models: 8720, 8807-01, 8808-01, 8807-51, 8808-51, 8826, 8835-01, 8841, 8842, 8855, 8860, 8861, 8860-50, 8861-50, 8860-51, 8861-51, 8420-51, 8421-51, 8422-51, 8730-10, 8731-10, 8847, MR8880, MR8880-20, MR8880-21, MR8875, MR8875-30, MR8740, MR8741, MR8827, MR6000, MR6000-01, MR8740-50, MR8848)
(2) WaveViewer (Wv) - Simple software for viewing measurement data
(Compatible models: 8807-01, 8808-01, 8714, 8715, 8835-01, 8841, 8842, 8826, 8720, 8855, 8825, 8840, 8420-01/51, 8421-01/51, 8422-01/51, 8730-10, 8731-10, 8860, 8861, 8860-50, 8861-50, 8860-51, 8861-51, 8847, 8870-20, 8870-21, MR8870-20, MR8870-30, MR8880, MR8880-20, MR8880-21, MR8847-01, MR8847-02, MR8847-03, MR8847-51, MR8847-52, MR8847-53, MR8875, MR8875-30, MR8740, MR8741, MR8827, MR6000, MR6000-01, MR8740-50, MR8848)
(3) MR8904 CAN Editor - Setting program for MR8904 CAN Unit.
(4) SF8000 Waveform Maker– Setting program for U8793, MR8790 and MR8791.
(5) USB device driver.
(6)Instruction manuals: MR8904, U8793, MR8790, MR8791.

2.After decompressing the downloaded file, double-click ”Index.htm” to begin.
　　　
3.To install WaveViewer(Wv), click ”Install” or ”Files” on the WaveViewer(Wv) page.
