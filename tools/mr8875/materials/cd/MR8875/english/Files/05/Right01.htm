Troubleshooting


If an operating problem occurs with the interface, check the following items.


LAN


• Is the cable properly connected?

→ Verify that the instrument is properly connected to the PC.
→ Use a cable with straight-through wiring when the instrument is connected to a hub.
→ Use a cable with crossover wiring when the instrument is connected directly to a 100BASE-TX interface on a computer.

• Is the IP address valid?

→ Refer to the preparation.

• Is the IP address of the instrument duplicated on another device?

→ Change the IP address.

• Is the power turned on?

→ Turn on all devices.

USB


• Is the cable properly connected?

→ Verify that the instrument is properly connected to the PC.

• Are the interface settings correct?

→ Check that USB has been selected.

• Is the power turned on?

→ Turn on all devices.
