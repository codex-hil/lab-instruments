Searching for Communication Errors


To confirm that communication commands are being properly transmitted, check the following.



The communication commands are not functioning properly.


• Is there a command error?

→ Enter [*ESR?] to view the error message displayed in the standard event status register.

• Is the processing of the communcation command causing the error?

→ Enter [:ERROr?] to see if a processing error has taken place.

• Are conditions set up for the communication commands to properly transmit?

→ Enter [:STATus?] to check the operating conditoins of the MEMORY HiCORDER.
