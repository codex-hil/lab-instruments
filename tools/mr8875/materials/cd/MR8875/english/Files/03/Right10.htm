KEY Command (Panel keys)


Enable/disable or query the remote mode


Syntax


(Command)
(Query)


:KEY:REMOte A$
:KEY:REMOte?

(Response)

A$
 A$ = OFF, ON


Details


Enables and disables instrument panel controls.
Returns the current remote state.


Example


:KEY:REMOte ON
:KEY:REMOte?
 (Response)  :KEY:REMOTE ON  (when headers are enabled)


Note


When remote is set to ON, manual operation of the main device is not available.
Remote settings will be turned OFF when the main device is retorted.
