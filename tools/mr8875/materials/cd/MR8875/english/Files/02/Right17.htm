SETting Commands (Set and read setting configurations)

 

Command

Data
(for a query, response data)

Explanation

:CLEAr A

A = 0 to 6

Clear a setting configuration

:COMMent A,"B$"

A = 1 to 6
B$ = comment string (up to 40 characters)

Enter a setting configuration comment

:COMMent? A

A<NR1>,"B$"

Query a setting configuration comment

:LOAD A

A = 1 to 6

Load a setting configuration

:PONNo A

A = 0 to 6

Set the selection number of the settings to load when the power is turned on

:PONNo?

A<NR1>

Query the selection number of the settings to load when the power is turned on

:PONSelect A$

A$ = OFF, ON

Enable or disable the loading of selected settings when the power is turned on

:PONSelect?

A$

Query the ON/OFF status for loading selected settings when the power is turned on

:SAVE A

A = 1 to 6

Save a setting configuration

:STATus?

[response] A<NR1>,B<NR1>
A = 1 to 6
B = 0, 1

Query a setting configuration status
