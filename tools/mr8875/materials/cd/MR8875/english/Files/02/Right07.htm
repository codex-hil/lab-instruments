CURSor Commands (Cursor setting and reading)

 

Command

Data
(for a query, response data)

Explanation

:DFREad? A$,B$

[response] A$,B$,C$,D$
A$ = A, B, C, D, E, F, B_A, D_C, F_E
B$ = F1～F4
C$ = <Readout value on x axis>
D$ = <Readout value on y axis>

Query the cursor readout values of FFT data

:DTREad? A$

[response] A$,B$
A$ = A, B, C, D, B_A, D_C
B$ = <readout value (time)>

Query a cursor readout value (time)

:DVREad? A$,CH$

[response] A$,CH$,B$(,C$)
A$ = A, B, C, D, E, F, B_A, D_C, F_E
CH$ = CH1_1 to CH4_15, LA to LB, L1 to L4, P1 to P2, W1_1 to W4_2, Z1 to Z8, XY1 to XY8, LAT, LON, ALT, DIR, SPD, DST
B$ = <readout value>
C$ = <readout value (recorder function or X-Y waveforms)>

Query a cursor readout value (measured value)

:FFTPos A

A = 0 to (number of stored data - number of FFT point)

Set the begining point of the FFT calculation

:FFTPos?

A<NR1>

Query the begining point of the FFT calculation

:FHPOsition A$,B

A$ = E, F
B = 0 to 500

Set the horizontal cursor position of the FFT waveform

:FHPOsition? A$

A$,B<NR1>

Query the horizontal cursor position of the FFT waveform

:FVPOsition A$,B

A$ = A, B, C, D
B = 0 to (number of calculted data - 1)

Set the vertical cursor position of the FFT waveform

:FVPOsition? A$

A$,B<NR1>

Query the vertical cursor position of the FFT waveform

:HCH A$,CH$

A$ = E, F
CH$ = ALL, CH1_1 to CH4_15, P1 to P2, W1_1 to W4_2, Z1 to Z8, F1 to F4, LAT, LON, ALT, DIR, SPD, DST

Set the horizontal cursor channel

:HCH? A$

A$,CH$

Query the horizontal cursor channel

:HENAble A$,B$

A$ = E, F
B$ = OFF, ON

Enable or disable the horizontal cursor

:HENAble? A$

A$,B$

Query the ON/OFF status of the horizontal cursor

:HPOSition A$,B

A$ = E, F
B = 0 to 500

Set the horizontal cursor position of the TY waveform (time-measured value)

:HPOSition? A$

A$,B<NR1>

Query the horizontal cursor position of the TY waveform (time-measured value)

:VCH A$,CH$

A$ = A, B, C, D
CH$ = ALL, CH1_1 to CH4_15, P1 to P2, LA to LB, L1 to L4, W1_1 to W4_2, Z1 to Z8, F1 to F4, LAT, LON, ALT, DIR, SPD, DST

Set the vertical cursor channel

:VCH? A$

A$,CH$

Query the vertical cursor channel

:VENAble A$,B$

A$ = A, B, C, D
B$ = OFF, ON

Enable or disable the vertical cursor

:VENAble? A$

A$,B$

Query the ON/OFF status of the vertical cursor

:VPOSition A$,B

A$ = A, B, C, D
B = 0...(number of stored data position)

Set the vertical cursor channel of the TY waveform (time-measured value)

:VPOSition? A$

A$,B<NR1>

Query the vertical cursor position of the TY waveform (time-measured value)

:XPOSition A$,B

A$ = A, B, C, D
B = 0 to (Displayed position or number of stored data position)

Set the X axis position of the XY waveform

:XPOSition? A$

A$,B<NR1>

Query the X axis position of the XY waveform

:XYHOri A$,B

A$ = E, F
B = 1 to 8 (waveform number)

Set the horizontal cursor at the XY waveform

:XYHOri? A$

A$,B<NR1>

Query the horizontal cursor at the XY waveform

:XYVErt A$,B

A$ = A, B, C, D
B = 1 to 8 (waveform number)

Set the vertical cursor at the XY waveform

:XYVErt? A$

A$,B<NR1>

Query the vertical cursor at the XY waveform

:YPOSition A$,B

A$ = E,F
B = 0 to 500

Set the Y axis position of the XY waveform

:YPOSition? A$

A$,B<NR1>

Query the Y axis position of the XY waveform
