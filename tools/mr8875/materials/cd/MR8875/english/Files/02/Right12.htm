SCALing Commands (Set and query scaling)

 

Command

Data
(for a query, response data)

Explanation

:CMODel CH$,A$

CH$ = CH1_1 to CH4_15
A$ = C3283, C3284, C3285, C9010_50, C9018_50, C9132_50, C9322, C9657_10, C9675

Set the scaling based on the clamp model

:CMODel? CH$

CH$,A$

Query the scaling based on the clamp model

:CRANge CH$,A

CH$ = CH1_1 to CH4_15
A = 1.0E-03 to 5.0E+03

Set the scaling range of the clamp

:CRANge? CH$

CH$,A<NR3>

Query the scaling range of the clamp

:CRATe CH$,A$

CH$ = CH1_1 to CH4_15
A$ = R10MA, R100MA, R1A, R10A, R20A, R50A, R100A, R200A, R250A, R500A, R1KA, R2KA, R2_5KA, R5KA, R1KV

Set the output rate for clamp scaling

:CRATe? CH$

CH$,A$

Query the output rate for clamp scaling

:DB CH$,A,B

CH$ = CH1_1 to CH4_15, W1_1 to W4_2
A = -200 to +200
B = -200 to +200

Set the scaling based on decibel (dB)

:DB? CH$

CH$,A<NR3>,B<NR3>

Query the scaling based on decibel (dB)

:INVErt CH$,A

CH$ = P1 to P2
A = -9.9999E+09 to +9.9999E+09

Set the number of pulses equivalent to one count of pulse scaling

:INVErt? CH$

CH$,A<NR3>

Query the number of pulses equivalent to one count of pulse scaling

:KIND CH$,A$

CH$ = CH1_1 to CH4_15, P1 to P2, W1_1 to W4_2, LAT, LON, ALT, DIR, SPD, DST
A$ = RATIo, POINt, SENSor, RATE, DB, RATING, RPM

Select the scaling method

:KIND? CH$

CH$,A$

Query the scaling method

:OFFSet CH$,A

CH$ = CH1_1 to CH4_15, P1 to P2, W1_1 to W4_2, LAT, LON, ALT, DIR, SPD, DST
A = -9.9999E+19 to +9.9999E+19

Set scaling offset (RATIO)

:OFFSet? CH$

CH$,A<NR3>

Query scaling offset (RATIO)

:RTDCapa CH$,A

CH$ = CH1_1 to CH4_15
A = +1.0000E-09 to +9.9999E+09

Set the scaling value for the rated capacity of a strain channel

:RTDCapa? CH$

CH$,A<NR3>

Query the scaling value for the rated capacity of a strain channel

:RTDOut CH$,A

CH$ = CH1_1 to CH4_15
A = +1.0000E-09 to +9.9999E+09

Set the scaling value for the rated output of a strain channel

:RTDOut? CH$

CH$,A<NR3>

Query the scaling value for the rated output of a strain channel

B = -9.9999E+29 to +9.9999E+29

CH$,A$

:UNIT? CH$
